Shuben Launcher website

1. Extract the whole zip first (right-click > Extract All), then open index.html in your browser.
   The .js and .css files are loaded by index.html. Do not double-click them.
2. The download buttons open your Google Drive links. To change a link, open config.js in Notepad
   (right-click > Open with > Notepad) and edit the DOWNLOADS lines.
3. To publish on GitHub Pages, upload everything in this folder (index.html at the top level).
   All files are small, so the normal GitHub upload works.
