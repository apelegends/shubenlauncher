Shuben Launcher

A Minecraft launcher for Windows and macOS with Microsoft login, a built-in mod and resource pack store, skins and capes, and one-click servers from modpacks.

DownloadWindows & macOS

Everything in one launcher

Microsoft login

Sign in with the official Microsoft flow. Your login is remembered, encrypted on your computer.

Default mode

No account yet? Default runs Mojang's free demo: time-limited and single-player only.

Skins & capes

Upload a skin and switch between the capes your account owns, right from the launcher.

Mod & resource pack store

Search Modrinth, filter by version and loader, and install with required dependencies in one click.

Servers from modpacks

Upload a Modrinth .mrpack and get a ready server: mods, Java and server software installed for you.

Always up to date

Checks for the newest releases and snapshots, and can auto-select the latest release for you.

Download

Windows 11.exe · 76 MB macOS Apple Silicon.dmg · 104 MB macOS Intel.dmg · 111 MB

Each button opens the file on Google Drive. Click Download there. For big files Drive may say it can't scan for viruses, so choose Download anyway.

Not sure which Mac you have? Apple menu → About This Mac. If the chip says Apple, use Apple Silicon. If it says Intel, use Intel.

The app is not signed, so Windows or macOS may warn you the first time. On Windows choose More info → Run anyway. On Mac, right-click the app and choose Open.
